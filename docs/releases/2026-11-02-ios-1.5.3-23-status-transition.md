# iOS 1.5.3 (23) — Retour du lecteur vers les menus

Complément au build 22 : la réapparition des indicateurs système peut ne modifier ni les dimensions de la WebView ni ses marges sûres. Après une sortie du lecteur, le dernier relevé pouvait donc encore indiquer une région d’occlusion vide, ce qui laissait les boutons d’un autre menu sous l’horloge.

Le pont natif actualise désormais les régions réservées après l’animation de visibilité UIKit. Il lit l’état présent au moment de ce relevé, y compris si une autre navigation est survenue entre-temps. La comparaison des instantanés évite les notifications identiques.

Le code web est celui du correctif du build 22, publié sur le site public avec le commit `0d46da8`. Le build 23 modifie uniquement le pont natif, les numéros de build de l’app et du widget, et ce bilan. Compilation Debug, vérification de signature et installation sur l’iPhone Duo physique réussies. Ce build n’est pas une soumission App Store ou une distribution TestFlight.
